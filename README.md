# 3Match Prototype

Unity용 간단한 3매치 프로토타입입니다.

구성:
- 색상 4종: 파랑, 빨강, 초록, 노랑
- 타일 모양: 네모
- 인접한 타일 2개를 클릭해서 스왑
- 가로/세로 3개 이상 연결 시 제거, 낙하, 재생성
- 같은 색 2x2 사각형으로 붙어도 제거
- 5개 일자 매치: 같은 색 전체 삭제 아이템 생성
- 세로 4개 매치: 세로 줄 전체 삭제 아이템 생성
- 가로 4개 매치: 가로 줄 전체 삭제 아이템 생성
- 아이템은 스왑해서 발동
- 아이템끼리 스왑하면 합성 효과 발동
- 특수 발동 시 약 1초 동안 강조 이펙트 후 제거
- 특수 발동과 연쇄 제거에 점수 배수 적용
- 제거 시 간단한 폭발 링 이펙트 표시

아이콘:
- 같은 색 전체 삭제: 흰색 원형/별형 아이콘
- 가로 줄 삭제: 흰색 가로 바 아이콘
- 세로 줄 삭제: 흰색 세로 바 아이콘

합성 효과:
- 색 전체 삭제 + 색 전체 삭제: 보드 전체 제거
- 색 전체 삭제 + 줄 삭제: 대상 색 전체 + 교차 줄 제거
- 줄 삭제 + 줄 삭제: 두 위치 기준 교차 줄 제거

파일:
- `Assets/Scripts/Match3/Match3Bootstrap.cs`
- `Assets/Scripts/Match3/Match3Game.cs`

사용 방법:
1. 이 폴더를 Unity 프로젝트 루트로 열거나, `Assets` 폴더를 기존 Unity 프로젝트에 복사합니다.
2. 빈 씬을 열고 Play 하면 게임 오브젝트가 자동 생성됩니다.
3. 마우스로 인접한 두 칸을 순서대로 클릭하면 스왑됩니다.
